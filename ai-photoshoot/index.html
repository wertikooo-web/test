Вопросы

Насколько будет похоже на меня?

Сходство сильнее всего зависит от исходных фото. Gemini 3.1 поддерживает несколько референсов и умеет сохранять внешность персонажа, но отдельные детали всё равно могут меняться.

Куда уходят мои фото?

Эта версия не загружает их на наш сервер. Браузер отправляет изображения напрямую в Gemini API при генерации.

Почему нужен API key?

GitHub Pages не умеет безопасно хранить серверные секреты. Для бесплатного хостинга ключ вводится вами и хранится только в памяти текущей вкладки.

Можно ли сделать полноценный публичный сервис?

Да. Следующий шаг: вынести API-ключ в Cloudflare Worker и подключить оплату, после чего пользователям ключ уже не понадобится.
